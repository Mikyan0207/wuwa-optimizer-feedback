# wuwa-optimizer feedback

This repository tracks bug reports, data corrections and feature requests for [wuwa-optimizer](https://wuwa-optimizer.com).

[Open an issue](https://github.com/Mikyan0207/wuwa-optimizer-feedback/issues/new/choose) · [View existing issues](https://github.com/Mikyan0207/wuwa-optimizer-feedback/issues)

## Choose the right form

- **Bug report:** a page or feature is broken or behaves incorrectly.
- **Incorrect calculation or data:** a score, damage result, effect, value or timing appears wrong.
- **Feature request:** you want to suggest a change or a new feature.

## Before submitting

Search the [existing issues](https://github.com/Mikyan0207/wuwa-optimizer-feedback/issues) first. If the same issue already exists, add any missing information there instead of opening another report.

Include:

- the URL of the affected page;
- a clear description of the problem;
- a screenshot or short video when it helps;
- for calculation issues, the team, equipment, sequences and displayed result.

Do not post passwords, access tokens, email addresses or private account information. Everything submitted here is public.

This repository only tracks feedback. The application source code is not hosted here.
